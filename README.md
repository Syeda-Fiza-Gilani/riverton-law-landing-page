# ⚖️ Riverton & Associates: Law Firm Landing Page

A responsive landing page for a fictional law firm, built with React and Vite. I made it to practice turning a UI design into working code, matching the layout, spacing, typography, and colors as closely as I could.

<img width="1561" height="798" alt="Riverton law firm landing page screenshot" src="https://github.com/user-attachments/assets/2326228f-f144-43ae-a369-e89c30fb444e" />

## Features
- Sticky navbar with smooth scrolling to each section
- Practice areas grid (Family, Business, Criminal Defense, Personal Injury, Real Estate)
- Stats band and a testimonials slider with clickable dots
- Contact form with a practice area dropdown
- Responsive layout for desktop, tablet, and mobile

## Built With
React, Vite, plain CSS with variables, Lucide React, Google Fonts (Newsreader and Manrope)

## What I Learned
- Building layouts with CSS Grid and Flexbox
- Making a page responsive with media queries
- Rendering page data (practice areas, reviews) from arrays with `.map()`
- Handling small interactions with `useState`
- How much small design details matter

## Run It
```bash
git clone https://github.com/Syeda-Fiza-Gilani/riverton-law-landing-page.git
cd riverton-law-landing-page
npm install
npm run dev
```
Then open `http://localhost:5173`.
